## 🔎 最近认真研究的一个问题

### [了解一家企业之后，它的关系还能告诉我们什么？↗](https://github.com/RookieZhou0617/risk-aware-financial-fraud-detection)

财务数据和年报已经告诉了我们很多。我的硕士论文想进一步看看：了解企业自身之后，企业间的关系能为造假检测补充什么？我先结合财务、文本和历史信息建模，再探索图结构里的增量信息。

仓库里有方法、结果与不确定性，也有一个可以动手跑的 PyTorch 合成数据示例。图信息在一些场景下有帮助，在另一些场景下也会带来负迁移，这些都是研究的一部分。

[逛逛项目](https://github.com/RookieZhou0617/risk-aware-financial-fraud-detection) · [跑个小示例](https://github.com/RookieZhou0617/risk-aware-financial-fraud-detection/tree/main/examples) · [结果与局限](https://github.com/RookieZhou0617/risk-aware-financial-fraud-detection/blob/main/docs/experiments.md)

这条研究线从本科就开始了：在**济南大学**读数据科学与大数据技术时，我用图神经网络和集成学习探索电信诈骗用户识别。从本科到硕士，类别不平衡与欺诈检测一直是我关注的问题。
